# Contributing

This project is vibecoded. Contributions welcome.

## Commit conventions
Use Conventional Commits:
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `style:` formatting
- `refactor:` code change without behavior change
- `chore:` tooling/deps
- `test:` tests

## Branching
Create a feature branch, open a PR against `main`.

## Code style
- ESLint/Oxlint via `npm run lint`
- Tailwind for styling
- Keep components small and focused.
