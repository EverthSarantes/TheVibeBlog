# Contributing

## ⚠️ Regla fundamental: 100% Vibecoding

**Este proyecto es un experimento de vibecoding.** Todo el código debe ser generado por IA.
El código escrito manualmente por humanos está **prohibido**.

- ✅ Usa IA (Copilot, ChatGPT, Claude, OpenCode, etc.) para generar todo el código
- ✅ Describe lo que quieres en lenguaje natural y deja que la IA lo implemente
- ❌ No escribas código a mano
- ❌ No copies/pegues código de Stack Overflow u otras fuentes sin pasarlo por IA
- ❌ No hagas "pequeños ajustes manuales" — pídele a la IA que los haga

Si encuentras un bug o quieres una feature, describe el problema o la funcionalidad
en lenguaje natural y deja que la IA genere la solución.

## Commit conventions
Use Conventional Commits:
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `style:` formatting
- `refactor:` code change without behavior change
- `chore:` tooling/deps
- `test:` tests

## Branching
Create a feature branch, open a PR against `main`.

## Code style
- ESLint/Oxlint via `npm run lint`
- Tailwind for styling
- Keep components small and focused.
- All code must be AI-generated.
